**`UNRESOLVED` is not a path and nothing here reads through it** (`bin/fusion-source-root`'s header carries the branch). The host sets `FUSION_PLUGIN_ROOT` on every `host.exec.v1` call, so on Prior `UNRESOLVED` is a broken bundle: say so, say the due checks were not run and stay due, and report it as a defect of the installed bundle. There is no session to restart. **A due selector is not a blocking check either way:** nothing here blocks the run, and a check not run stays due.
