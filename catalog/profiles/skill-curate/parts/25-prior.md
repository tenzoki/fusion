3. **How to undo it** — the revert paths, which each entry carries. The apply pass's edits reach the user's checkout uncommitted. For a git-tracked surface the revert is therefore, until the user commits them, a discard of that path's working-tree edits (`git restore -- <path>`, after `git diff -- <path>` where the file held uncommitted edits before the run), and after the user's commit that commit's parent for the path. An entry whose file is not under version control says in those words that no revert path exists.
