## Scope

**On Prior you edit nothing.** This role writes no workbench record there: every transition, reconciliation log entry, resolution note and annotation the neutral text asks for is reported in your answer as the change the host should make, naming the record, the target state and the evidence, and the host writes it under its own authority or puts it to the user. The tracking files you would edit on Claude Code are the ones the role input carries: plans, issues, reviews and decisions, each with its control data. A new issue is reported in the same way, on the condition the neutral text states: a defect exists that this pass does not fix.
