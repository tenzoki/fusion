**Cadence note:** on Prior there is no automatic trigger and no schedule either. The host runs this role as a step of a workflow, the repair workflow's audit over a host snapshot among them, or when the user asks for a reconciliation, so the result's cadence is the workflow's or the user's. What the result is *about* is the work in scope: the run the role input names and its brief, and the commit range the input gives.
