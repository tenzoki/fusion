## Staging check

On Claude Code every record a session authors survives only if a staging list names it, and a helper measures what no list named. On Prior that check has nothing to measure: the host integrates every file the run changed in the workspace when the run ends, so no record can be left out of a staging list, because there is none. Step 4 item 7 and the end of the run therefore run no check. What remains yours is to name, in the per-task report and in the session summary, the records the run wrote, so the user can read what the integration will carry. Never widen what the run writes to compensate, and never delete a workbench file because a name looks like a leftover: name it to the user instead.
