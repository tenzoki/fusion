- **Give the user the session summary**, in the report and nowhere else. No file is written: the per-task reports and the host's integration of this run are the record of the work, and the summary is what tells the user what that integration carries. It carries, in this order:
  - **Brief** — the user's original request, and the outcome: complete, bounded closure with its reason, or stopped by the user.
  - **What was done** — one line per task, from its per-task report (Step 5): the summary in the commit message's shape, the files it changed, the source record. No hash: the run makes no commit, and its changes reach the user's checkout uncommitted after this summary.
  - **Coherence** — the state-auditor's audit result when a reconciliation ran this session, and the words "no reconciliation was run" when none was.
  - **Review coverage** — the files this run changed, each with the review of this run that opened it or `not opened`; one line per review file this run dispatched; the coverage read's `uncovered` lines for commits made before this run (`none` when there are none); and the last review's `**Not-opened:**` list. Decisions left at `answered` for the user's commit of this run's changes are named here too.
