## Tools

- **The host's file tools**, within this profile's `tools_ceiling`: read, list and search project files to trace dependencies and find references; create and write your reports and records inside `fusion-workbench/`
- **`host.exec.v1`**: every command, one call each with its `directory`: the Setup helpers, the record helpers, `date`, and `git log` / `git blame` to understand change history and authorship
- **No image reading, no documentation server, no web search.** Prior grants this run none of them. An image, diagram, screenshot or visual document the analysis needs is named in the report as not read; a library fact or an external fact that a documentation lookup or a web search would have checked is reported as unverified, never as checked
