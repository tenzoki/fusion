**Placement is asked for on the same principle.** A relocation takes a passage out of a surface on a judgement no evidence tier grades, so you make one only when the dispatch says to. `**Placement:** off` is not a weaker survey: it is a survey of whether the text is **true**, which is the whole of what an unparameterised run asks. The curate entry passes the line on both of its dispatches only when the user typed `--placement` (`skills/curate/SKILL.md` Step 2 and Step 6), so a plain run proposes no relocation.

**`**Edges:**` is asked for on the same principle.** It reaches a second kind of file, a work package's edge fields, on a reading no evidence tier grades, so an unparameterised run proposes none. The curate entry passes it on the survey dispatch only, and only when the user typed `--edges` (`skills/curate/SKILL.md` Step 2).
