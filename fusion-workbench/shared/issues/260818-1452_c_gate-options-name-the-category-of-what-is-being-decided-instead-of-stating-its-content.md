**Severity:** Medium
**Domain:** code
**Filed by:** user, reported from a consuming project
**Affects:** `rules/user-facing-output.md` `## Questions and gates`
**Cross-references:** `shared/issues/260815-0752_*_no-agent-may-revise-an-active-circle-records-directive-so-a-revision-leaves-it-contradicting-the-spec.md` — the defect the quoted gate was about, and the reason the wording mattered

---

## The defect

An orchestrator gate asked the user to choose between two options phrased as categories:

> Der Circle-Datensatz verspricht eine Einschränkung, die es nicht mehr gibt. Die Entscheidung
> von 260814-1228 hält eine Fähigkeit fest, die nie gebaut wurde: einen Lauf verwerfen und neu
> anfangen.

The user is choosing between "eine Einschränkung" and "eine Fähigkeit". Neither names what it
actually is. The constraint that no longer exists is not stated; the capability is stated only in
the second half and only for one of the two options. A reader cannot tell what either choice
commits them to without opening the cited records, which is exactly what a gate exists to spare
them.

The identifier is wrong on top of that: `260814-1228` is a **Circle directory**, not a decision
record, and the sentence calls it "die Entscheidung von 260814-1228".

## What the rule requires today, and what it does not

`rules/user-facing-output.md` `## Questions and gates` already requires plain-English options,
self-contained questions, a marked default, and a statement of what each option forecloses. All
four can be satisfied by the text above: "eine Einschränkung" is plain English, the question is
self-contained in the sense that it needs no scrollback, and a foreclosure clause could be added
without making the option any more concrete.

What no clause requires is that an option state the **substance** of the thing it decides rather
than its type. That is the gap. "A constraint that no longer exists" is a category with a
referent the reader cannot recover; "the Circle record still promises that a run can be discarded
and restarted, which was never built" is the same length and is the actual content.

## The user's statement of the requirement

> Die Entscheidungspfade müssen unbedingt immer inhaltlich dargestellt werden, zwar durchaus
> kurz, aber präzise.

Short is compatible with this. The failure is not length, it is abstraction: naming the class of
a thing where the thing itself would have fit.

## Fix direction

Add one clause to `## Questions and gates` requiring that an option name what is at stake in its
own words, not by its type — and pair it with the same before/after treatment the rest of that
rule uses, since the existing clauses are all demonstrated rather than asserted. The rule file is
always-on, loaded by every agent on every dispatch, so the addition has to be tight; the
universal-core growth bound is the binding constraint.

Note that this defect is about a rule every agent obeys, and the quoted instance was produced by
the orchestrator, which is the agent that puts the most gates in front of a user.

---

**Resolved:** 260818 — `rules/user-facing-output.md` `## Questions and gates` now carries the
clause "An option names the thing it decides, not the kind of thing", demonstrated with the
quoted instance itself (the promised-but-never-built discard-and-restart capability) in the same
`Not X → Y` form the neighbouring plain-English clause uses. The clause states in its own text
that the substantive form is usually the same length, so it cannot be read as a request for
longer options against the four-line cap in `## Length`, and that it is not the foreclosure
clause restated: that one says what a choice rules out, this one says what the option is.

Cost: +750 bytes on an always-on rule file. The universal-core growth bound went from 6 716 to
7 466 bytes above its 86 573-byte baseline, leaving 4 534 of the 12 000-byte head-room. No
baseline was touched; `hooks/lib/__tests__/fixtures/rules-emission.golden` was regenerated by its
documented command and its diff is the one file's size plus each agent's total, nothing else.

`agents/orchestrator.md` was deliberately not edited, although it produced the failing gate: the
rule is what every agent reads, and a second copy in one prompt is how this project's guidance
drifts.

The wrong identifier noted in `## The defect` (a Circle directory called "die Entscheidung von
260814-1228") is a separate fault and is not addressed here — it is a citation error, not an
abstraction one, and no clause added to this section would have caught it.
