## What was asked

A defect transferred from a consuming project: `portfolio.md` is regenerated by playmaker on
every run, and its path citations name their targets under a written-out state marker instead
of the wildcard `_*_`, so a citation dies at its target's first marker transition and a hand
correction lasts only until the next run. Two sites named in the record. Plus: check whether
the same gap reaches Circle records, and report rather than widen.

## What was changed

**1. `rules/circle-records.md` — new `### Citation form in the portfolio` (+1 589 bytes).**
Placed at the end of the portfolio template, which is where playmaker is told to look
(its Setup step 4). Two paragraphs: the rule with its reason on the page (regeneration, so a
literal marker expires and a hand correction is overwritten), and the distinction the source
record insisted on — a **pointer to a file** is starred; the **naming of a marker** keeps its
letter, because there the letter is the statement. Binding decision and the measuring record
cited, both in the wildcard form.

**2. `agents/playmaker.md` — the examples and a pointer.** Both occurrences of
`260510-0930_*_token-format.md` moved to `_*_`: process step 3 (the site the record named) and
`## Output Style` (the same example repeated, which the record did not measure — reported to
the user rather than passed over). `## Output — the portfolio` gained a short paragraph naming
the rule and restating the pointer-versus-naming distinction, citing the rule section rather
than restating it.

**3. `hooks/lib/__tests__/portfolio-citation-form-lint.test.ts` — new gate, 14 tests.** Fails
`npm test` on any `YYMMDD-HHMM_<letter>_` token in `agents/playmaker.md`. The stamp in the
pattern is what encodes the distinction: it fires on a pointer to a file and never on a marker
being named (`_a_ → _t_`, `_t_circle.md`, `## Recently closed (_c_ / _b_)`, the marker table).
The file set is one file on purpose — elsewhere a stamped literal marker is legitimate
(`skills/migrate/SKILL.md` demonstrating a rewritten path field,
`rules/decision-record-examples.md` walking the transitions), so widening would need an
exemption list. A second assertion keeps the gate from going vacuous if the example is ever
deleted.

**4. `hooks/lib/__tests__/fixtures/rules-emission.golden` — regenerated** for the
`circle-records.md` size change (9 305 → 10 894 bytes), via
`UPDATE_RULES_GOLDEN=1 npx vitest run lib/__tests__/rules-emission-golden.test.ts`.
