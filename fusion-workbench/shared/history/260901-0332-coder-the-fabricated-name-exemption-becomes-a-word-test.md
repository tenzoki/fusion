## What was done

The `fabricated-name` exemption in the citation grammar keyed on a bare substring test for the
three letters of the placeholder slug. It fired on the English word `footer`, which this project
files records about, so sixteen store-prefixed citations in this repository's own workbench were
never judged by the checker and never rewritten by the sweep, and the release gate asserting
`rewrites=0` was green over them.

What changed, one bullet per file:

- `hooks/lib/citation-scan.ts`: the substring test became a named constant `FABRICATED_NAME`,
  matching the placeholder only where the slug's own delimiters open and close it. The constant
  carries a docstring; the file header gained a paragraph beside the other exemption paragraphs,
  saying that the test is a word test and why a substring test on three letters inside a corpus of
  hyphenated slugs will keep finding new English words.
- `hooks/lib/__tests__/citation-grammar-boundaries.test.ts`: one case with a row per assertion — a
  token carrying `footer` is judged, a token carrying the standalone placeholder is exempt, and the
  placeholder behind a literal marker is exempt too.
- `hooks/dist/`: regenerated by `npm run build`.
- `hooks/lib/__tests__/fixtures/surface-growth.golden`: regenerated by its documented command. The
  diff is one line and the total, +18 lines. The hook-test surface had 107 of its 2 500 lines free
  and now has 89.

## The delivered test is not the one the dispatch spelled

The dispatch named `/\bfoo\b/`. Measured against the corpus before writing anything, that spelling
would have been wrong in the other direction: JavaScript counts `_` as a word character, so the
seven genuine fixtures spelled `<stamp>_<marker>_<placeholder>.md` would have stopped being exempt.
That is six new dangling rows and a seventeenth store-prefixed rewrite beyond the sixteen the
finding predicted, in records where the name is fabricated by design.

The delivered predicate opens and closes the word on anything that is not a letter or a digit, so
`_`, `-`, `.` and `/` all delimit it. It exempts every token the old test exempted for the right
reason and none of the seventeen it exempted for the wrong one. The two spellings were compared
row by row over all 44 exempt tokens before the edit.

## What was deliberately not done

The sweep was not run with `--write`. Running it over this repository's own workbench is a
hand-run act behind its own census guard, and the census above is what a human reads before
authorising it. Nothing was committed. All twelve files the census names sit in closed (`_c_`)
Circles or in the shared stores; no live plan and no active Circle is among them.
