The citation sweep rewrites a review an evidence record binds by hash, and the reviewer wrote store-prefixed citations into one
---
Two gates on the same bytes pull against each other. `hooks/lib/__tests__/citation-sweep.test.ts` asserts that `bin/fusion-citation-sweep --dry-run` reads `rewrites=0` over this repository's workbench, so a workbench `.md` carrying a store-prefixed citation (`reviews/<stem>.md`, `plans/<stem>.md`) turns `npm test` red until the sweep rewrites it. An evidence record (`bin/fusion-write evidence`) binds its report by `report.sha256`, and the codec reads a record whose report bytes differ as `missing-evidence/report-changed` (`codec/src/store.ts:453`), which `hooks/lib/__tests__/workbench-citation-lint.test.ts` turns into "control file did not read". The sweep prints `bound=<file> report:<evidence>` for a file an evidence record binds and rewrites it anyway; and a correction (`<basename>.<n>.evidence.json`) is admitted only over an unchanged report, so a swept report can be re-bound under no basename it already has (`conflict/record-exists`, `codec/src/cli/ops.ts`, the evidence operation).

Measured on 2026-11-10 in this repository. The closing review `261110-1327-reviewer-closing-pass-over-the-campaign-package.md` of the campaign package was written with 46 store-prefixed citations and bound at `7ccb1728`; the sweep test was red from that commit. `--write --yes` rewrote 47 citations (46 in the review, 2 in the package narrative's closure note), the evidence record stopped reading, three citation-lint tests failed, and the re-bind was refused. The repair restored the package, plan, decision and narrative to their bytes at `15530b7c`, deleted the unpushed evidence record, issued a new one over the swept review and finished the package again — a redo of a closure, possible only because nothing had been pushed.

Two causes, each its own fix. The reviewer wrote citations in the store-prefixed form into a record that was about to be bound, which `rules/fusion-workbench-conventions.md`'s citation rule does not admit and nothing in the reviewer's prompt or the evidence operation refused. And the sweep's `bound=` line is a report, not a refusal: the one case where a rewrite destroys a reading is the one case it goes ahead on.
