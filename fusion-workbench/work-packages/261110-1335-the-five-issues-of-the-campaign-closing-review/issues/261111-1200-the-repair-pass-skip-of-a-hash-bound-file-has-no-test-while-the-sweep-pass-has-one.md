The `--repair` pass's skip of a hash-bound file has no test, while the sweep pass's skip has one
---
`hooks/citation-sweep.ts` skips a file a record binds by hash in both passes: `skipIfBound` (line 977) is called from the `--repair` branch (line 1013, `if (n === 0 || skipIfBound(abs, n)) continue;`) and from the sweep branch (line 1067). The header (lines 356-360) and `bin/fusion-citation-sweep` (lines 57-61, "no write in either pass, no count in files=, rewrites= or repairs=") state the rule for both. `hooks/lib/__tests__/citation-sweep.test.ts` proves it for the sweep pass alone: the case added at `ee1a4984` ("leaves a report an evidence record binds as written in --write --yes ...") runs `--dry-run` and `--write --yes`, reads the bytes back and reads the record through the codec; the earlier case ("skips a plan and a spec adopted and a report an evidence record binds ...") asserts the three `bound=` lines of a dry-run sweep. No case runs `--repair` over a bound file: the one `--repair` case over a JSON-controlled workbench is the own-repository `repairs=0` check (line 808). The repair branch collects its rows into `rows` and `classes` before the skip and counts them only after it, a reordering the diff introduced on both branches, so the branch whose counting changed most is the one no test reads.
