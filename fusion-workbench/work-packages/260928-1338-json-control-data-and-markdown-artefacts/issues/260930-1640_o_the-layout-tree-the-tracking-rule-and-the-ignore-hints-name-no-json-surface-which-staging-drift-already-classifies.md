Seen while reading row 7: `agents/orchestrator.md` line 189 routes a task touching `package.json` to `code-implementer`. A work package's control file has that name, and only the codec writes it.

**Whether row 7 needs a line in FJ03d: yes, one.** The class column already gives the right act, "stage it". Two things are missing. First, the row's subject is no longer only "an authored artefact": a `package.json` or `*.record.json` the codec wrote is also a `record` row, and Step 4's shape ("every path passed to `git add` is one you wrote out yourself") could read as a reason not to stage a file the session did not author. Second, a `PAIR-SPLIT` row means the other half is already staged: stage the unstaged half in the same commit, and never commit one half alone. The `in-flight` row's examples gain `workbench.json` and `.json-state/`.
