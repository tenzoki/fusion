An Answered: line citing nothing resolvable defaults answer_ref to the original with no derived entry
---
`composeProposal` (`hooks/lib/legacy-import.ts`, the decision branch of the records loop) sets `answer_ref` to the record's own original in two cases. When the `Answered:` line is missing or empty it writes `derived["/control/answer_ref"] = {rule: "answer-ref-self", evidence: "no-answer-line" | "empty-answer-line"}`. When the line exists but cites nothing resolvable (the `else` branch that raises the `answer-ref-self` finding) it writes the same default and no `derived` entry. The plan's stopping clause requires one for every derived or defaulted control value.
