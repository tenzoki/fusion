# C5 — the history store is closed to writes

**Status:** Complete
**Filed by:** coder, Kai Stalmann <ks@qantr.com>

Step C5 of `260909-1843_*_implementation-cut-fusion-to-a-working-minimum.md`. The
session-history store stops taking writes. The corpus already in it is untouched: 1046
entries across 33 `history/` directories, listed before and after, diffed empty.

## What changed

**All fifteen agent prompts.** No prompt names `$OUT_HISTORY` or `$SCAN_HISTORY` any more.
Where a prompt had a "log the session" step, the step is gone and the run's report to whoever
dispatched it is stated as the only record. Three prompts needed more than a deletion:

- `agents/curator.md` — the run file is the ledger the apply pass reads back, so it could not
  simply go. It moved to `$OUT_ANALYSIS`, the existing kind for a written survey with
  citations, rather than a new store. Session histories left the evidence pass, which is
  seven sources now; `git log --follow` carries what they carried, because the commit message
  is the per-commit record.
- `agents/reconciler.md` — the reconciliation log and the `## Coherence` append into the
  orchestrator's history file both go; both are report sections now, and the orchestrator
  reads the verdict there. Setup's Directive and session anchor come off the dispatch prompt,
  since neither the state file nor the history file exists to hold them.
- `agents/orchestrator.md` — Setup steps 6 to 8 collapse into one ceremony step that emits
  `session_start` and nothing else; the `history_file` field leaves that event; the
  end-of-session summary becomes the report; the post-session sequence diagram goes, having
  had exactly one destination.

**`bin/fusion-paths`** keeps both arms valued and says why in its header: two skill bodies
outside this step's file list still name `$OUT_HISTORY`, and removing an arm a shipped prompt
names is exit 4 rather than silence.

**`rules/fusion-workbench-conventions.md`** — `## History Logging` becomes `## Session
history`: the store is closed, the corpus is kept and stays citable, and a pass that digests
it says its coverage past the cut is nil. `rules/workbench-path-resolution.md` marks both keys
legacy in the key table.

**`skills/cadence/SKILL.md`** states the cut in `**Sources scanned:**` and in `## Notes`, so a
window with no session-log unit reads as a closed store and not as a quiet week.
`skills/post/SKILL.md` drops the history basename from its pointer block.

**Tests.** `fusion-paths.test.ts` loses the assertions on the two keys and gains a pin: no
agent gets either key, `/fusion:cadence` still gets `SCAN_HISTORY`. Its "every agent gets at
least one key" case now names `editor` as the one agent that writes nothing in the workbench.
