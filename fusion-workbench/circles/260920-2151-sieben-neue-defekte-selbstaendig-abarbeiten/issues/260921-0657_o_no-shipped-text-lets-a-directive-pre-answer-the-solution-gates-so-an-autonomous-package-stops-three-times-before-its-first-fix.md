No shipped text lets a directive pre-answer the solution gates, so an autonomous package stops three times before its first fix
---
A work item whose directive says the package is to be worked autonomously (`260920-2151-sieben-neue-defekte-selbstaendig-abarbeiten.md`: "selbständig ausführen"; its predecessor `260918-1048-defekte-selbstaendig-abarbeiten-mit-zweitmeinung.md`: "drei Tage ohne Rückfrage") reaches the orchestrator's `## Human Gate Rules` table unchanged. That table stops the session on a produced plan, on every claim, release and finish of a work item, and on a plan's stop conditions, with no clause that reads the directive as the answer. The session of 2026-09-21 stopped three times before the first fix (the claim, the previous item's stop conditions, the plan) and was told by the user that the feature does not work at all.

The feature is not in the tree. `grep -rniE 'autonom|unattended|without asking|pre-answer|selbständig'` over `agents/`, `rules/`, `skills/`, `hooks/lib/*.ts` finds no mode, no directive clause and no gate exemption. The session of 2026-09-18 passed the same plan gate by writing its own `gate_response` as `proceed (pre-answered by the user in the directive: decide everything yourself, no questions until the package is done)` (`fusion-workbench/orchestrator-events.jsonl`, `2026-09-18T09:31:38`), which is one session's reading and not a mechanism: the next session, reading the prompt as written, asked.

Evidence: `agents/orchestrator.md` `## Human Gate Rules` (the table and the interaction pattern under it), `## Work items` ("Each is confirmed for that operation, on that item, before a byte moves"), `## Closing a work item` step 3; the `gate_hit`/`gate_response` rows of 2026-09-21 and 2026-09-18 in the event log.

Acceptance: the orchestrator prompt states, once, which gate conditions a directive can pre-answer (the ones the directive of `260918-1048` itself splits off as "die Lösung selbst": the plan review, the claim of the item the directive names, the stop-conditions read at its close) and which it never can (ontology, removing or rebuilding something that exists, an ambiguous mandate: filed as an open decision and skipped); a session working an item whose directive carries the autonomy sentence emits `gate_response` rows with the directive cited as the answer and puts no question to the user for the pre-answered kinds; a session working an item without it asks as today. `hooks/lib/__tests__/` need not gain a case: the acceptance is a read of the prompt and of one event log.
