# The `**Proposal source:**` stamp is carried into the second dispatch and nothing ever compares it

**Filed by:** coderev (review of Circle `260813-0858-playmaker-maintains-backlog-store`, commit `b995049`)
**Severity:** Medium
**Scope:** `agents/playmaker.md` `### A confirmation carried by the dispatch prompt`; `skills/next/SKILL.md` Step 5b

## What is carried

Both halves of the relay carry the same line (`skills/next/SKILL.md:172`, `agents/playmaker.md:216`):

```
**Proposal source:** <portfolio> `## Backlog — ranked`, generated <stamp from the portfolio header>
```

`agents/playmaker.md:207` says what it is for: *"`**Proposal source:**` names where that analysis is written down, for a line that needs its context."* That is a **read pointer**. Nothing in either file tells the second run to compare the stamp it was handed against the `**Generated:**` value in the portfolio header it opens, and nothing says what to do if the two differ.

## The window it would close

The portfolio is overwritten in full by every playmaker run (`agents/playmaker.md:58`). Between the two dispatches of one relay sits an unbounded interval: the user is answering an `AskUserQuestion`. During it the portfolio can be regenerated by an orchestrator Phase 4 dispatch in a second session, or by a second `/fusion:next`. fusion has no concurrency lock and says so (`CLAUDE.md`, "Single orchestrator per project — advisory").

The second run would then open a portfolio whose `## Backlog — ranked` section describes a different state, while performing confirmed operations copied from an analysis that no longer exists on disk. The failure is not loud: the operation lines still parse, the entry paths still resolve, and the writes land. The stamp is the exact instrument that would detect this, and it was added — it just does nothing.

## Why it matters more than the probability suggests

The stamp already costs a line in two files. Making it load-bearing is one sentence; leaving it inert means a reader who meets it reasonably concludes a staleness check exists.

## Recommendation

One sentence in `agents/playmaker.md` `### A confirmation carried by the dispatch prompt`: before performing anything, compare the stamp on `**Proposal source:**` against the `**Generated:**` value in the portfolio you open. On a mismatch, perform **no** operation, regenerate nothing, and report that the proposal you were handed was superseded — the user re-runs `/fusion:next` and confirms against the current analysis. That is the behaviour the gate already implies (*"you may not act on a confirmation given for a different entry, given in an earlier session"*, `agents/playmaker.md:200`), stated where the mechanism can act on it.
