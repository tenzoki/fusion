# May an agent read the session transcripts as a source of evidence?

**Domain:** code
**Filed by:** orchestrator
**Cross-references:** `circles/260821-1042-reply-bounded-whole-question-answered/_*_circle.md`

## Question

The workbench stores no chat replies, so the only reproducible record of what an agent actually said to
the user is the session transcript under `~/.claude/projects/`. Those files sit outside the repository
and contain the user's own prompts. This Circle's subject is reply length and register, so without them
it has no baseline at all.

The question was put after the fact rather than before: the shaper had already read them to produce
this Circle's Grounding figures, 2 231 replies across 69 sessions with 398 over the 12-line cap. The
gate therefore asked whether it may continue, not whether it may happen.

## Options

1. **Yes, as a source of evidence.** Counts and verbatim quotation both.
2. **Yes, aggregated only.** Counts and distributions, no verbatim quotation of the user's prompts.
3. **No.** The two filed records are the only evidence.

## Answer: option 1, yes, as a source of evidence.

## What this forecloses

The user's own prompts can appear as quotations in workbench records, and those records are committed.
Anyone reading this repository's history reads them too. A before-and-after specimen of a real reply is
the thing this buys, and it is not obtainable any other way.
